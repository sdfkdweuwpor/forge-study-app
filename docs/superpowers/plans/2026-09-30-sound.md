# Sound (generated lofi + noise mixer) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A layered sound system for Forge: 9 adjustable noise layers plus 10 generated lofi styles, saved mixes, playing on any page from an organized Sound panel and a mini player.

**Architecture:** Everything audible lives in `src/lib/audio/` on the existing single AudioContext + limiter: noise layer builders, a mixer with one gain per layer and a music bus, and a lazily loaded music engine (pure composer → instruments → look-ahead player). Pure rules (mix defaults, migration from today's `ambient`, clamping, presets) live in `src/logic/soundMix.ts`. The UI stays in the Focus feature (`src/features/focus/sound/`): a `SoundHost` in `global.overlays` owns playback (one elected tab), a `SoundPanel` in `focus.aside`, a `MiniPlayer` in `sidebar.footer`.

**Tech Stack:** React 19 + TypeScript, Dexie (settings row), Web Audio API (no audio files), Vitest (Node, pure tests + a fake AudioContext), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-09-30-sound-design.md`

## Global Constraints

- Generated in-app only: no audio files, no streaming, no new dependencies.
- Lofi styles (10, ids in this order): `classic`, `rainy`, `coffee`, `tokyo`, `synthwave`, `electronic`, `jazzhop`, `piano`, `chillhop`, `space`; labels "Classic lofi", "Rainy day", "Coffee shop", "Tokyo night", "Synthwave", "Electronic", "Jazz hop", "Sleepy piano", "Chillhop morning", "Space ambient".
- Noise layers (9, ids in this order): `rain`, `storm`, `wind`, `campfire`, `cafe`, `waves`, `birds`, `creek`, `noise`; labels "Rain", "Heavy rain & thunder", "Wind", "Campfire", "Café chatter", "Ocean waves", "Forest birds", "Creek", "Noise". `noise` has a colour: `white` | `pink` | `brown`.
- Settings change is additive: `settings.sound.mixer?` (no `SCHEMA_VERSION` bump); absent → derived from `sound.ambient` / `sound.ambientVolume`.
- Device-only (never synced): `settings.sound.device` = `{ playing: boolean; open: { lofi: boolean; sounds: boolean; mixes: boolean } }`; add `'sound.device'` to `SETTINGS_DEVICE_PATHS`.
- Volumes 0..1 clamped; presets max 12, names trimmed to 40 chars; unknown styles/layers dropped.
- Layer rules: logic → db → ui/lib → features → app; features never import `@/db/db` outside `queries.ts`; no `any`, no `console.*`.
- Initial JS ≤ 180 KB gzip (`node scripts/perf/initial-js.mjs dist`); `src/lib/audio/music/*` is reached only through `import()`.
- Machine: Playwright `--workers=4` max; one e2e run at a time; helpers never run e2e in parallel.
- Commit after each task; push after each phase (tasks 6, 9, 10); never put a model name in commits; `[skip ci]` except the phase-final commit.

## Review Focus

1. **Autoplay blocked** (Play pressed before any gesture reached the page, or "start with focus" on a fresh load): nothing throws, the panel shows Play as pressed, sound starts on the next click/key. Test in Task 5.
2. **Two tabs open:** only one plays; closing it hands playback to the other when it comes to the front. Test in Task 6 (e2e, two pages).
3. **Old settings rows** (a user with `ambient: 'rain', ambientVolume: 0.3` and no `mixer`): the panel shows Rain at 30% and nothing else on. Test in Task 1.
4. **Slider dragging:** 60 updates a second write settings at most every 250 ms and ramp gains (no zipper noise, no DB storm). Test in Task 5.
5. **Background tab throttling:** the music look-ahead drops missed bars instead of playing a burst when the tab wakes. Test in Task 8.
